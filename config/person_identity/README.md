# Canonical person identity seed

Disse CSV-filene er en sanitert, versjonert kopi av identitetsgrafen som brukes til å bygge nettsiden reproducerbart i et nytt arbeidsområde.

Byggeskriptet vedlikeholder filene automatisk. Kopien omfatter stabile person-ID-er, offentlige navnealiaser, sammenslåinger, slug-historikk og eventuelle resultatoverstyringer. Private eksterne ID-er, manuelle vurderingsnotater og beslutningskøer skal aldri legges her.
